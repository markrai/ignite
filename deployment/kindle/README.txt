Ignite for Kindle
=================

Version: see the folder name of this package


Before you begin
----------------
Ignite requires a Kindle that has already been prepared for third-party
applications (jailbreak / community firmware tools, SH Integration, and a
root helper). If your Kindle has not been prepared, stop. Ignite will not
jailbreak or prepare a stock Kindle. For jailbreaking, follow:
https://kindlemodding.org/jailbreaking/

Verified on a Kindle Scribe (1st generation), firmware 5.18.6, 32-bit ARM.
Other Kindle models and firmware versions are untested. This is beta software.


Send this one file to the person installing
-------------------------------------------
Install Ignite

That is the only file they need. Do not send a ZIP or extra folders.


Install Ignite
--------------
You need a Kindle Scribe and a phone or computer that can copy a file over USB.

1. Download Install Ignite.
2. Connect the Kindle with USB.
3. Copy the Install Ignite file into the Kindle Documents folder.
4. Eject / disconnect the Kindle.
5. On the Kindle, open Install Ignite.
6. When installation succeeds, open Ignite.


Upgrade
-------
Leave Ignite (go to the Kindle Home screen) if it is open.
Then follow the same steps as Install Ignite.

Your notebooks are kept.


Backup
------
Open Backup Ignite Data from the Kindle Library periodically.

Then connect the Kindle by USB and copy your Ignite backup folder from the
Kindle to somewhere safe.

Older backups are kept. This package does not restore a backup for you.


Uninstall
---------
Open Uninstall Ignite.

Your notebooks are preserved.


If something goes wrong
-----------------------
- Copy Install Ignite into the Kindle Documents folder again and retry.
- If the Kindle says Ignite is still open, go to Home, wait a moment, and
  try Install Ignite again.
- Copy Ignite-Diagnose from Documents over USB. The installer writes this
  report even if Diagnose Ignite is not in the Library yet.
- After the payload unpacks, Diagnose Ignite is in the Library; open it and
  copy Ignite-Diagnose over USB.
- Your notebooks are not deleted by a normal install, upgrade, or uninstall.
