# Authentic Ignite screenshots

Public README images must be **photographs or device captures of real Ignite**,
not generated, mocked, or reconstructed substitutes.

Capture them during hardware qualification of a release candidate (see
[`docs/release-packaging.md`](../release-packaging.md)):

| File | Subject |
|------|---------|
| `library.jpg` | Kindle Library showing **Ignite** after install |
| `notebook.jpg` | Open notebook with real handwriting |
| `sync.jpg` | Optional: pairing / sync with Ignite Server (only if that feature is advertised) |

Commit the files next to this note and embed them in the root `README.md`.
Do not add placeholder or AI-generated images.
